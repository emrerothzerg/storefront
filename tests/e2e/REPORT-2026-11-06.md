## Defects
- D1 High — soft 404s (HTTP 200 + noindex + client-side not-found). Cause: PPR flushes the 200 shell before `notFound()`.
- D2 Medium — `/checkout` redirect delivered as `<meta http-equiv=refresh>` (200) instead of 3xx. Same cause.
- D3 Medium — no-JS form-post results exist only in the RSC payload; with JS disabled all content stays in hidden PPR chunks ("Loading…").
- D4 Medium — `Route "/checkout": unstable value crypto.randomUUID() while prerendering` logged on every render.
- D5 Low — two stale/flaky unit tests (CartTable copy; session test vs mocked next/navigation).

## Decision
Orchestrator: disable `cacheComponents`/PPR (every page is cookie/DB dependent; PPR adds no value and breaks HTTP semantics). Re-run this script after the change; D1–D4 are expected to clear.

## Still needs a browser (Playwright approval pending)
JS-enabled checkout (pending state, key rotation, double click), hydrated feedback and refilled values, focus management, live regions, keyboard reachability, error.tsx retry, responsive layout.

## Questionable, not violations
Secure cookie requires HTTPS off-localhost; "Test mode" card list is in production HTML; declines write `payment_failed` orders; cold start 70–150 ms vs ~2 ms warm.
