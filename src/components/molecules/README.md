# molecules

Small compositions of atoms that form one UI unit. Still presentational: data arrives through props. Owner: programmer.

## Rule

**Molecules compose atoms only; no raw HTML controls, no server imports.** Use the atoms in `src/components/atoms` (`Button`, `Input`, `Link`, `Image`...) instead of `<button>`, `<input>`, `<a>`, `<img>`; plain layout elements (`<div>`, `<article>`, `<ul>`) are fine. Never import from `src/server/**`. Token rules from `src/components/atoms/README.md` apply (`bun run check:tokens`).
